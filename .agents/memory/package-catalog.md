---
name: Package catalog
description: Product rule for keeping voucher offers in one admin-managed catalog.
---

Use Admin → Paket as the single source for sellable voucher offers. The hotspot portal and customer dashboard should consume that catalog rather than maintaining separate offer lists. Admin → Voucher creates individual access credentials; those credentials are not public catalog entries.

**Why:** The user asked for “1 paket dengan admin saja biar 1 jalur” so new offers follow one admin workflow and stay consistent.

**How to apply:** Keep every customer purchase surface on the same package records and eligibility rules. Do not expose generated voucher usernames or passwords as public products.
